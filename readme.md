## ✨ Key Features
* **Secure Login Simulation:** Entry restricted via a 4-digit PIN validation.
* **Add Money:** Users can increase their account balance through a dedicated input field.
* **Cash Out:** Functional withdrawal system that deducts amounts from the current balance.
* **Dynamic UI Toggling:** Seamlessly switch between 'Add Money' and 'Cash Out' views without page reloads using JavaScript.
* **Responsive Design:** Fully optimized for mobile and desktop views using **Tailwind CSS** and **DaisyUI**.

---

## 🛠️ Technologies Used
* **HTML5:** Semantic structure.
* **Tailwind CSS:** Modern utility-first styling.
* **DaisyUI:** Accessible UI components (buttons, cards, and modals).
* **Vanilla JavaScript:** Core logic, data processing, and DOM manipulation.

---

## 🧠 Core Logic & Learning Outcomes
In this project, I implemented the following programming concepts:
1.  **Event Listeners:** Used `addEventListener` to capture user interactions like clicks and form submissions.
2.  **Data Extraction:** Captured `value` from input fields.
3.  **Conditional Logic:** Applied `if-else` blocks to verify PIN codes and ensure the withdrawal amount does not exceed the current balance.
4.  **DOM Updating:** Dynamically updated the `innerText` of balance elements to reflect real-time changes to the user.
